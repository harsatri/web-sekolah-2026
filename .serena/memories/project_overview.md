# Project Purpose
The project is a school management web application ("Catur WebSekolah 2026"). It includes a backend API and a frontend React application to manage school data, eligibility submissions, and user authentication.

# Tech Stack
- **Backend**: Node.js, Express, MySQL (mysql2), Multer (file uploads), dotenv.
- **Frontend**: React, Vite, Tailwind CSS, React Router DOM, Leaflet (maps).
- **Database**: MySQL.

# Architecture
The project is split into two main directories:
- `backend/`: Node.js server.
- `frontend/`: React single-page application.
