# Pertanyaan UAT Sistem Kelayakan Calon Siswa

Dokumen ini berisi contoh pertanyaan User Acceptance Testing (UAT) yang dapat digunakan dalam kuesioner penilaian. Skala yang disarankan:

- 1 = Sangat Tidak Setuju
- 2 = Tidak Setuju
- 3 = Cukup Setuju
- 4 = Setuju
- 5 = Sangat Setuju

## A. UAT untuk Admin Sekolah

| No | Pernyataan | Aspek Penilaian |
| --- | --- | --- |
| 1 | Halaman login admin sekolah mudah dipahami dan digunakan. | Kemudahan penggunaan |
| 2 | Dashboard admin sekolah membantu saya memahami jumlah dan kualitas hasil simulasi yang masuk ke sekolah. | Kejelasan informasi |
| 3 | Data pengguna yang direkomendasikan ke sekolah saya mudah dicari dan dibaca. | Kemudahan akses data |
| 4 | Fitur filter dan pengurutan pada daftar pengguna direkomendasikan membantu saya menemukan data yang dibutuhkan lebih cepat. | Efisiensi kerja |
| 5 | Informasi detail hasil simulasi calon siswa sudah cukup jelas untuk dipahami. | Kejelasan output |
| 6 | Hasil breakdown skor SAW membantu saya menjelaskan alasan rekomendasi sekolah kepada pihak lain. | Transparansi hasil |
| 7 | Fitur unduh PDF pada data simulasi membantu kebutuhan dokumentasi sekolah. | Kegunaan fitur |
| 8 | Fitur edit profil sekolah memudahkan saya memperbarui informasi sekolah. | Kemudahan pengelolaan |
| 9 | Fitur pengajuan perubahan kriteria mudah digunakan dan sesuai kebutuhan sekolah. | Kesesuaian fungsi |
| 10 | Status pengajuan kriteria mudah dipantau melalui sistem. | Monitoring proses |
| 11 | Sistem ini membantu sekolah memantau minat dan kecocokan calon siswa secara lebih terstruktur. | Manfaat sistem |
| 12 | Secara keseluruhan, sistem layak digunakan sebagai alat bantu prescreening calon siswa di sekolah. | Penerimaan sistem |

## B. UAT untuk User Biasa / Orang Tua

| No | Pernyataan | Aspek Penilaian |
| --- | --- | --- |
| 1 | Proses membuat akun dan login ke sistem mudah dilakukan. | Kemudahan akses |
| 2 | Menu dan tampilan pada halaman utama mudah dipahami. | Kemudahan penggunaan |
| 3 | Informasi sekolah yang tersedia pada sistem membantu saya mengenal sekolah tujuan. | Kegunaan informasi |
| 4 | Form simulasi kelayakan mudah diisi langkah demi langkah. | Kemudahan input |
| 5 | Istilah kriteria pada form simulasi mudah dipahami. | Kejelasan bahasa |
| 6 | Sistem memberikan pesan yang jelas ketika ada data yang belum lengkap atau salah input. | Kejelasan umpan balik |
| 7 | Hasil simulasi kelayakan mudah dipahami setelah proses selesai. | Kejelasan hasil |
| 8 | Rekomendasi sekolah yang ditampilkan sistem terasa relevan dengan data yang saya input. | Relevansi hasil |
| 9 | Penjelasan status kelayakan dan skor hasil simulasi membantu saya memahami posisi calon siswa. | Transparansi hasil |
| 10 | Sistem ini bermanfaat sebagai simulasi awal sebelum proses pendaftaran resmi sekolah dasar. | Kemanfaatan sistem |
| 11 | Sistem membantu saya membandingkan kemungkinan rekomendasi sekolah dengan lebih cepat. | Efisiensi pengguna |
| 12 | Secara keseluruhan, saya puas menggunakan sistem kelayakan calon siswa ini. | Kepuasan pengguna |

## C. Pertanyaan Terbuka untuk Admin Sekolah

| No | Pertanyaan |
| --- | --- |
| 1 | Fitur apa yang paling membantu pekerjaan Anda pada sistem ini? |
| 2 | Bagian mana dari sistem yang masih membingungkan atau perlu diperbaiki? |
| 3 | Apakah hasil simulasi yang ditampilkan sudah cukup membantu untuk analisis awal calon siswa? Jelaskan. |
| 4 | Saran apa yang Anda berikan agar sistem lebih sesuai dengan kebutuhan sekolah? |

## D. Pertanyaan Terbuka untuk Orang Tua

| No | Pertanyaan |
| --- | --- |
| 1 | Bagian mana dari sistem yang paling mudah digunakan menurut Anda? |
| 2 | Apakah ada bagian form simulasi yang membingungkan saat diisi? Jelaskan. |
| 3 | Apakah hasil rekomendasi sekolah sudah cukup membantu Anda? Mengapa? |
| 4 | Saran apa yang Anda berikan agar sistem lebih nyaman digunakan oleh orang tua? |
